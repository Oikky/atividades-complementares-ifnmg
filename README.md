# Atividades Complementares — IFNMG (kit)

Kit pra montar o requerimento de Atividades Complementares do IFNMG Campus Montes Claros com o Claude Code.

```powershell
git clone https://github.com/Oikky/atividades-complementares-ifnmg
```

Abra o Claude Code dentro da pasta clonada e cole o texto de [`PROMPT.md`](PROMPT.md).

- `MOLDE - ... .docx` — formulário em .docx, em branco, já com o curso Integrado (90h)
- `Formulario original (em branco).doc` — modelo oficial
- `REGRAS.md` — regras do PPC e tetos por categoria
